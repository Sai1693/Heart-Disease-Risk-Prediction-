# Heart-Disease-Risk-Prediction-
# ❤️ Heart Disease Risk Prediction

## Overview

Heart Disease Risk Prediction is a Machine Learning based academic major project that predicts the possibility of heart disease using patient health parameters.

## Features

- Data preprocessing
- Machine Learning model training
- Risk probability prediction
- Interactive Streamlit dashboard
- Model evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Machine Learning

## Machine Learning Algorithm

- Logistic Regression

## Dataset Features

- Age
- Gender
- Chest Pain Type
- Blood Pressure
- Cholesterol
- Heart Rate
- ECG Results
- Exercise Angina
- ST Depression
- Other cardiac parameters
